====================================================
 C4Graph Ver 2.0 セットアップ手順
====================================================

【必要なもの】
 ・Google Chrome（インストール済みであること）

【セットアップ】

 1. このフォルダ（C4Graph）を丸ごと、お好きな場所にコピーしてください。
    例: C:\Apps\C4Graph 、ドキュメントフォルダ など

 2. 「CreateShortcut.bat」をダブルクリックしてください。
    → デスクトップに「C4Graph」ショートカットが作成されます。

 3. デスクトップの「C4Graph」アイコンをダブルクリックすると
    アプリが起動します。

【ショートカットを作らない場合】

 ・「C4Graph.bat」をダブルクリックでも起動できます。

【注意事項】

 ・初回起動時、インターネット接続が必要です
   （グラフライブラリをCDNから読み込むため）。
 ・フォルダ内のファイル構成は変更しないでください。
